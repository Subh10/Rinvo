# Licensing checklist

Rinvo's original source code is MIT-licensed. This does not automatically apply to upstream model code, pretrained weights, dependencies, datasets, sample voices, or generated assets.

Before public v0.1.0 release with real inference, verify and record:

- Exact upstream repository and immutable revision for the candidate model.
- Separate license terms for code and checkpoints/weights.
- Commercial-use and redistribution permissions, attribution and notice requirements.
- Dependency licenses and any model download terms.
- Whether sample audio is generated from authorized text/voices and may be redistributed.

Until this review is complete, do not claim that the complete model stack is MIT-licensed or unrestricted for commercial use.
